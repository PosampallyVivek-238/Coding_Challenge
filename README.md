<h5>Learning Basic git commands<h5><br>
List of Git commands:

1. git config --global user.name
2. git config --global use.email
Above commands are used to configure github in the local system. 

3. git config --list
It is used to check which account we are using.

4. git clone https link
It is used to clone the global data to local data.

5. git status 
It is used to check the status of changes made.
The status may be of untracked, modified, unmodified, staged.

6. dir, cd, mkdir
7. git add file_name or .
